Dans ce Lab, vous apprenez à organiser votre temps pour réaliser les tâches du projet technique dans les délais.

1. Comprendre la gestion du temps

La gestion du temps consiste à organiser le travail, choisir les priorités et respecter les délais.

2. Notions à découvrir

Priorité : choisir les tâches les plus importantes.

Estimation : prévoir le temps nécessaire pour une tâche.

Planning : organiser les tâches et les dates.

Délai : connaître la date limite d'une tâche.

Suivi : vérifier le travail réalisé et le temps utilisé.

Imprévu : savoir réagir à un problème ou à un retard.

3. Règles de travail à appliquer

Lire la tâche avant de commencer.

Définir les étapes du travail.

Estimer la durée de chaque tâche.

Respecter les dates et les délais.

Commencer et terminer les tâches dans le temps prévu.

Mettre à jour l'état de chaque tâche.

Signaler les problèmes et les retards.

Éviter les distractions pendant le travail.

4. Règles de validation du Lab

Présenter un planning de travail.

Définir les priorités et les durées.

Montrer le suivi des tâches.

Présenter les temps prévus et les temps utilisés.

Expliquer les problèmes rencontrés et les solutions.

Respecter les délais et déposer les livrables demandés.
