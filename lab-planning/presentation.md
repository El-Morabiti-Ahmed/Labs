# Exemple appliqué au portail e-sport

Les sept parties suivantes montrent comment adapter la trame au projet d’ajout et de consultation de jeux.

---

## 1 — Page de garde : portail e-sport

Ce Lab présente un portail e-sport par **Ahmed El Morabiti**, encadré par **ES-SARRAJ FOUAD**.

---

## 2 — Plan : portail e-sport

Nous verrons le besoin, la stack PHP-JavaScript-JSON, les notions, le parcours d’ajout et le résultat.

---

## 3 — Stack technique : portail e-sport

PHP répartit le traitement entre `games.php`, `gameManager.php` et `gameController.php`, JavaScript remplit le tableau et JSON conserve les jeux.

---

## 4 — Définitions : portail e-sport

JSON est un format de stockage structuré, un contrôleur reçoit les actions et JavaScript met à jour le tableau dans le navigateur.

---

## 5 — Problème et besoin : portail e-sport

Les utilisateurs ont besoin d’ajouter un jeu avec son nom et sa plateforme, puis de retrouver ces informations dans un tableau.

---

## 6 — Solution et pratique : portail e-sport

L’utilisateur ouvre le formulaire, saisit le jeu, l’enregistre, puis vérifie sa présence dans le tableau et la notification de statut.

---

## 7 — Résultats et conclusion : portail e-sport

Les jeux enregistrés dans JSON alimentent le tableau et le bouton signale l’envoi par « Enregistrement... », ce qui illustre la coopération de PHP, JavaScript et JSON.
