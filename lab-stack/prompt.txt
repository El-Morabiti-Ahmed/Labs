Mon projet technique est un portail e-sport qui permet d'ajouter des jeux dans un tableau. Un bouton affiche un formulaire où l'utilisateur entre le nom du jeu et sa plateforme.

Les données sont enregistrées dans un fichier JSON, puis récupérées pour remplir le tableau.

Le projet utilise trois classes PHP : games.php, gameManager.php et gameController.php. JavaScript est utilisé pour récupérer les données et remplir le tableau.

Il y a aussi un bouton « Enregistrer » qui affiche « Enregistrement… » pendant l'envoi des données. Une notification informe l'utilisateur si l'enregistrement a réussi ou non.
